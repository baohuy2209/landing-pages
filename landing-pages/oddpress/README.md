# Oddpress

An imaginary independent print club with an interactive two-ink poster lab. Built with Next.js and fully customized shadcn/ui (Base UI).

```bash
pnpm install
pnpm dev
```

Run `pnpm typecheck` and `pnpm build` before delivery. `pnpm start` serves the production build.

## The experience

Browse six original SVG posters, filter by subject, then choose an artwork, two inks and a registration offset in the lab. Download the result as a self-contained SVG. The workshop planner is a local demonstration: it does not submit data, take payment or make reservations.

The page includes responsive navigation, keyboard-accessible tabs, slider, dialog and accordion, scroll reveals, reduced-motion support and a pause control for the continuous decorative animations. All artwork and fonts are local.

## Art direction & research

- [RISOTTO](https://risottostudio.com/) — expressive print culture, tactile surfaces and a playful relationship with colour.
- [Risolve](https://risolvestudio.com/) — spot-ink combinations as a creative constraint.
- [Roller Ink](https://www.rollerinkriso.com/) — stencil layers and the character of registration variation.
- [Ór Studio](https://orstudio.ie/) — an independent studio voice and accessible experimentation.

The original design uses warm paper, dense Dela Gothic One lettering, poppy red, oxblood and cobalt, with ink overlap rather than photographs. No reference artwork or branding is copied. The ink lab is a playful digital simulation, not a calibrated print proof. Oddpress is not a real shop or workshop provider.

Fonts: Dela Gothic One (Latin subset from Google Fonts) and Manrope, under SIL Open Font License; licenses are in `app/fonts`. Poster exports use a system sans-serif for portability. Code and original illustrations follow the collection's MIT license.
