# Tempo — creative research

The direction is a warm, light chess gallery: sculptural ceramic pieces, a single vermilion queen and oversized Archivo typography. Its visual rhythm differs from the collection’s darker immersive worlds.

- [Check Mate King, Undream](https://www.undreamstudio.com/projects/checkmateking/): chess as an editorial, cinematic subject. Tempo takes a distinct light palette and a tactile, educational approach.
- [WebGL Scroll Sync, Lusion](https://webgl-scroll-sync.lusion.co/): sustained spatial continuity while the HTML tells the story. Pieces travel, regroup and return to the same complete board.
- [Paper Planes, Active Theory](https://paperplanes.world/): a small, meaningful action can make an immersive world engaging. Tempo’s game controls move real pieces, rather than ornamental pointer effects.
- [Kasparov–Topalov game score, ChessBox](https://www.chessbox.in/chessgame/kasparov-garry-topalov-veselin-30/): complete main line, replayed locally without annotations.
- [25 years later, Chess.com](https://www.chess.com/pt-BR/news/view/25-anos-atras-kasparov-topalov-1999): date, round, players and resignation after 44. Qa7.
- [Laws of Chess, FIDE](https://handbook.fide.com/chapter/E012023): board orientation and the basic movement of each piece.

All models, board artwork and textures are created procedurally for Tempo. No external 3D assets or reference source code are reused.
